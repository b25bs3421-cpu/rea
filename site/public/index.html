02 · the contract

One record, six honest facets

An agent can act on this without trusting prose. Every field below appears in the JSON, including the uncomfortable ones.

Observations 01

What was read, and from where. Nodes, occurrences, edges and source ranges — never a paraphrase of them.

Locations 02

Every claim points at a file, an artifact path or a source range, so a reviewer can reopen the exact bytes.

Confidence 03

Observed, derived or inferred, plus the authority that produced it — bytes, a parser or a static inference rule.

Coverage 04

Complete, complete-within-substeps or bounded, with omitted counts when a limit was reached. Silence is never implied success.

Limitations 05

What the provider could not do on this host, stated in the record instead of being left for the reader to guess.

Unknowns 06

Residual questions stay in the graph as labelled unknowns with a reason — ambiguity is data, not noise to drop.

05 · run it

Three commands from here

The site is static. The analyses are not: run them from a checkout, or open the local console for the same workflows with a UI.

install and inspect 
# install once, then connect your agent
npm install -g rea-agents
rea setup

# inventory any package, no engine required
rea inspect-artifact ./app.zip --json

# reconstruct a JavaScript application
rea analyze-javascript-application ./extracted-app --json

Every command in this site is listed in the command reference and every tool in the tool catalog.

MCP client configuration 
{
  "mcpServers": {
    "rea": {
      "command": "npx",
      "args": ["-y", "rea-agents@latest"]
    }
  }
}
▸ Want the UI? The Workbench console runs the same workflows against a local checkout, with uploads, path mode and evidence downloads: npm run workbench then localhost:5180.

06 · limits

What this site will not pretend

Static pages cannot run an analysis. They also should not hide what the host could not do.

Static by design

Captured, not live

The two datasets were captured on 2026-10-26 from arena/5cca6736-rea@8fef2aa. They do not update when you read the page.

Engines

No native engine here

Hopper, Ghidra and IDA are not installed in this build, so the site demonstrates the engine-free workflows only. The record says so rather than implying deeper analysis.

Sources

Summaries, with links

Documents are indexed by title, summary and section headings; the prose stays in the repository so there is one source of truth.
