Workflows

The two things you can run without an engine

REA ships 193 tools, but the shortest path to understanding it is two workflows that need nothing installed but Node. Both samples below were captured from this checkout — every number is a real result.

01 · app reconstruction

analyze-javascript-application

Point it at an extracted Electron or web app. It reads syntax and files, never runs them.

Input
  • A directory, an .asar, or a single .js / .json file.
  • Sample used here: website/public/examples/notes-electron — a small notes app with one IPC channel.
  • Resolution happens inside the inventoried container; nothing outside it is read.
What the record contains
  • File inventory with digests, parse status and text inclusion.
  • Electron roles: main, preload, renderer, windows, package, bridges.
  • IPC channels with both sides and source locations.
  • 45 relationship edges plus the semantic graph.
  • 71 retained unknowns across 4 families.

02 · artifact inventory

inspect-artifact

Give it a package. It returns a graded artifact graph with digests, containment edges and coverage — no engine involved.

Input
  • ZIP, ASAR, APK, DMG, .app, a raw binary, or any package file the provider recognizes.
  • Sample used here: notes-electron.zip — 2,587 bytes, packed from the notes example.
  • Directories are rejected with a remediation, because this workflow reads a file.
What the record contains
  • Artifacts deduplicated by digest, each graded by how completely it is materialized.
  • Every occurrence: logical path, entry kind, hash status, executable and encrypted flags.
  • Containment edges, integrity contradictions, hypotheses and next probes.
  • Coverage across substeps, with omitted counts when a bound is hit.
