144 commands, one binary

The terminal surface mirrors the MCP tools: the same workflows, the same Evidence, scriptable. Search the list, copy a command, and add --json when you want the record instead of the rendering.

the shape of every command 
rea <command> [target] [flags]

# machine-readable output
rea inspect-artifact ./app.apk --json

# discover the surface
rea --help
rea inspect-artifact --help
Notes
  • --json prints the Evidence document; without it you get the human rendering of the same record.
  • 1 command keep 1 historical alias so scripts keep working.
  • Local console runs the same entry point, scripts/rea.mjs, so its results cannot drift from the CLI.
