# HEADSHOT.io recreation brief

A detailed, copy-ready Google AI Studio prompt for a browser FPS recreation brief named **HEADSHOT.io**.

## Deliverables

- `HEADSHOT_io_Complete_Game_Recreation_Prompt.pdf` — formatted prompt document.
- `HEADSHOT_io_Google_AI_Studio_Prompt.md` — editable/copyable source prompt.

The prompt specifies gameplay systems, five weapon classes, six modes, six maps, controls, HUD, bots, local economy, cosmetics, audio, accessibility and acceptance checks. This repository contains a design prompt, not a playable game or online multiplayer service.

The PDF was rebuilt from the saved prompt after earlier visual reference image files were no longer available in the workspace. It contains the full text specification but does not embed those screenshots. The prompt itself describes the reference-image intent and notes that HEADSHOT is an independent fan-made concept, not affiliated with DEADSHOT.io.
